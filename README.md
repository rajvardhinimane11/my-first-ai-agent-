# Simple AI Chatbot

## Project Description

This project is a simple AI chatbot developed using Python.
The chatbot interacts with the user through the command line
and provides responses based on keywords present in the user's input.

## Features

- Greets the user
- Answers simple questions
- Provides basic information about Python and AI
- Responds to thanks
- Allows the user to exit by typing "bye"

## Requirements

- Python 3.x
- No external libraries are required

## How to Run

1. Install Python 3.x.
2. Save the program as `chatbot.py`.
3. Open the terminal or command prompt.
4. Run:

```bash
python chatbot.py
